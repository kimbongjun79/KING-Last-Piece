# KING: Last Piece — 에이전트 인수인계 (작업 방식)

프로젝트 구조는 직접 확인할 것. 이 문서는 **같은 방식으로 개발을 이어가기 위한 규칙과 관례**만 담는다.

## 기본 규칙
- 사용자와는 **한국어**로 대화한다. 코드 주석·커밋 메시지는 영어(주변 코드 스타일 그대로).
- 모든 변경은 **컴파일 확인 → 커밋 → push**까지 한 번에 끝낸다. 커밋 메시지 끝에 `Co-Authored-By` 한 줄을 붙인다.
- 사용자가 켜 둔 **Unity 에디터는 절대 종료하지 않는다.** (에디터가 프로젝트를 잡고 있어 배치모드 실행 불가)
- 요청이 모호하면 짐작해서 구현하고, 무엇을 어떻게 해석했는지 답변에 밝힌다. 큰 설계 결정(보스 사양, 제한시간 등)만 질문한다.

## 커밋하지 않는 것
NamuFX 폴더, 3D Skybox 팩(이미 커밋된 것 제외), `Assets/Sounds/`, `Docs/Sound/prompts.md`, PerformanceTestRun json,
`ShaderGraphSettings.asset`·URP/RP 에셋·ProjectSettings 등 에디터가 건드린 설정 잡음, 에디터가 만든 LightingData 폴더.
씬 파일은 **사용자가 씬 반영을 원할 때만** 커밋한다(에디터 저장 잡음과 섞이기 쉬움).

## 검증 방식 (가볍게)
- 컴파일 체크: `Assembly-CSharp(-Editor).csproj`를 복사해 `dotnet build`로 확인 (Editor 스크립트 포함 버전도 사용).
- 동작 확인이 꼭 필요할 때만 씬 복사본을 **배치 빌드 + `-autoshot <dir>`** 로 돌려 스크린샷·tsv 로그를 본다
  (`Assets/Scripts/Lab/*Shots.cs`가 각 씬용 캡처 스크립트). 사용자가 "테스트 그만"이라 하면 즉시 중단.
- 시각적 결과(조명·이펙트·UI)는 **사용자가 에디터에서 직접 검수**한다. 장황한 씬 테스트는 만들지 않는다.

## 씬에 반영하는 방법 (중요)
- 월드·교실은 씬에 **베이크**되어 있다. 에디터가 열려 있으므로 씬은 `Assets/Scripts/Editor/LookPass.cs`로 갱신한다.
  - 버전 상수를 올리면 에디터가 컴파일 후 **자동으로 1회 실행**되어 4개 씬을 열고 저장한다(메뉴로도 실행 가능).
  - 런타임 코드로 만든 오브젝트는 LookPass에서 재생성해야 씬에 저장된다. 런타임 머테리얼·메시는 에셋으로 저장해야 한다.
  - 컴포넌트 기본값을 바꿔도 **씬에 직렬화된 값이 이긴다** → LookPass에서 컴포넌트를 새로 만들어 적용.
  - 에디터 정적값(예: `BoardSlots.Size`)이 플레이 후 남아 있을 수 있으니 LookPass에서 명시적으로 설정.
- 교실 오브젝트는 **Static(배칭)** 이라 플레이 중 이동이 반영되지 않는다(체스 시계 버그 원인). 움직일 것은 씬에서 미리 배치.

## 코드 작업 관례
- 셸로 C# 수정 시 `sed`/`perl`에 `|`·`[` 패턴 주의 (파일 손상 사례 다수) → 여러 줄 수정은 Edit 도구 사용.
- 새 스크립트·에셋은 기존 `.meta`를 복사하고 **새 GUID**로 만든다. 텍스처 노멀맵은 meta의 textureType/sRGB 확인.
- 한 단계 수치 = 피해·생존 약 5%. 아이템 등급 일반/희귀/영웅/전설, 아이템은 종류별 1회만 획득.
- 능력치 상한은 모두 해제 상태(기력 절약은 소모량 0에서 멈춤). 특수 아이템 쿨: 스테일메이트 180초, 갬빗 60초.

## 에셋·아트 파이프라인
- 아이템 아이콘: Varco(체스 플로우, nano-banana-2, 1:1)로 **기존 아이콘을 EditImage**로 수정 → 초록 크로마키 생성 →
  로컬 합성 스크립트로 등급별 배경(그라데이션+테두리, 체크무늬 없음) 합성. 체스 요소는 1~2개만, 흑백 위주 권유.
- 이펙트는 새 에셋보다 **기존 NamuFX 프리팹·Tazo 텍스처를 재활용**한다. 비대칭 슬래시는 좌우반전 2겹으로 대칭 처리.
- 내장 텍스처 FBX(Varco 모델)는 `ClassroomBake.EnsureTextures`로 텍스처 추출 후 사용.

## 현재 게임 상태 요약
- 일반모드: 10라운드(+증원), 다크 기물 혼합, 최종 보스 체스메가트론, 어두운 홀 조명(`HallAmbience`).
- 무쌍모드(구 무한모드, EndlessMode 씬): 12×12, 30분 생존, 뱀서식 소환 디렉터(`MusouDirector`/`MusouPatterns`),
  2분마다 로그 곡선 강화·5회마다 크기 증가, 퀸 보스 7:30/15:00/22:30, 레벨업 3택1(체력 1/5·기력 회복).
- 게임 화면에는 불필요한 텍스트를 두지 않는다(체력 숫자·조작 안내 등 제거됨).
