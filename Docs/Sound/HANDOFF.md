# 사운드 생성 작업 인계서 (VARCO)

> 이 문서는 **다른 AI 에이전트가 단독으로 읽고 작업할 수 있도록** 작성된 지시서입니다.
> 이 대화의 맥락 없이도 이 폴더의 파일만으로 작업을 끝낼 수 있습니다.

## 작업 목표
게임 **KING: Last Piece**에 필요한 효과음·BGM 96종을 **VARCO 사운드 생성 기능**으로 만들어,
정해진 파일명으로 저장합니다.

## 입력 파일
| 파일 | 내용 |
|---|---|
| `sounds.json` | **작업 대상 목록 (기계용, 이 파일을 기준으로 작업)**. 96개 항목, 각 항목에 생성 프롬프트·길이·변형 개수·저장 경로 포함 |
| `SoundList.md` | 같은 목록을 사람이 읽기 좋게 정리한 표 + 구현 참고사항 (참고용) |
| `refs/<id>.jpg` | **사운드별 상황 이미지** (실제 게임 화면, 1280×720). 그 소리가 나는 바로 그 순간을 캡처한 것 |
| `refs/_overview_1.jpg`, `_2.jpg` | 전체 96장을 ID 라벨과 함께 모아 본 한눈 보기 |

## 상황 이미지 사용법
- 각 항목의 `image` 필드가 해당 이미지 경로입니다 (`sounds.json` 기준 상대 경로).
- VARCO에 이미지 입력(이미지→사운드, 참고 이미지)이 있으면 **프롬프트와 함께 이미지를 넣어** 생성합니다. 이미지 입력이 없으면 이미지를 보고 프롬프트를 보강하는 데 씁니다 (예: 무엇이 무엇에 부딪히는지, 크기, 분위기).
- 이미지는 게임을 자동으로 플레이하며 그 사운드 이벤트가 처음 발생한 순간(몇 프레임 뒤)을 찍은 것입니다. 흰색 기물 = 플레이어(킹), 검은색 기물 = 적, 붉게 빛나는 기물 = 공격 준비 중인 적, 붉은 바닥 = 적 공격 범위 경고.
- 음악·앰비언스·UI 항목(`BGM_*`, `AMB_*`, `GAME_*`, `UI_*`)의 이미지는 "그 소리가 깔리는 화면"입니다. 화면 속 동작에 맞춘 효과음이 아니라 분위기 참고용입니다.
- `UI_Hover`, `UI_Confirm`은 게임에 아직 메뉴가 없어 타이틀 화면으로 대체했습니다 (`image_note` 참고).
- 이미지 재생성: 게임 빌드를 `-soundrefs <폴더>` 옵션으로 실행하면 같은 방식으로 다시 찍힙니다 (`Assets/Scripts/Lab/SoundRefCapture.cs`).

## 게임 톤 (모든 프롬프트 공통)
`sounds.json`의 `style` 값을 매 프롬프트 앞에 붙이거나, VARCO에 스타일/분위기 입력란이 있으면 거기에 넣습니다.

- 어두운 대리석 홀에서 **체스 말들이 싸우는** 소울라이크 아레나 액션
- 질감: 대리석·석재·흑단. **금속 칼 소리 금지** (킹은 몸 전체로 휘둘러 공격)
- 짧고 펀치감 있는 게임 효과음, 건조한 소리 + 짧은 석조 홀 잔향

## 항목 필드 설명 (`sounds.json` → `sounds[]`)
| 필드 | 의미 |
|---|---|
| `id` | 사운드 고유 ID (파일명에 사용, 바꾸지 말 것 — 게임 코드가 이 ID로 연결됨) |
| `folder` | 저장 하위 폴더 (`Assets/Audio/` 아래) |
| `priority` | P1 필수 / P2 완성도 / P3 폴리시 → **P1부터 생성** (53종) |
| `space` | 3D = 월드 위치음 → **모노**, 2D = UI/전역 → 스테레오 |
| `loop` | true면 **끊김 없는 루프**로 생성 (시작과 끝이 자연스럽게 이어져야 함) |
| `variations` | 같은 프롬프트로 생성할 개수 (조금씩 다른 버전) |
| `duration_sec` | 목표 길이(초). 생성 후 앞뒤 무음은 잘라냄 |
| `image` | 상황 이미지 경로 (`refs/<id>.jpg`) |
| `desc_ko` | 한국어 설명 (게임 내 상황) |
| `prompt` | VARCO 생성 프롬프트 (영문). 한국어 입력이 더 잘 나오면 `desc_ko`를 참고해 번역해도 됨 |

## 저장 규칙
```
Assets/Audio/<folder>/<id>_<NN>.wav     # NN = 01, 02, ... (variations 개수만큼)
Assets/Audio/<folder>/<id>.wav          # loop: true 이거나 variations: 1 인 항목
```
예) `HIT_Light` (variations 5) → `Assets/Audio/SFX/Hit/HIT_Light_01.wav` ~ `HIT_Light_05.wav`
예) `BGM_Boss` → `Assets/Audio/BGM/BGM_Boss.wav`

- 형식: WAV, 48 kHz, 피크 -1 dB 정규화, 앞뒤 무음 제거
- BGM은 용량이 크면 `.ogg`도 허용 (파일명 동일, 확장자만 변경)

## 작업 순서
1. `sounds.json`을 읽고 `priority == "P1"` 항목부터 처리 → 그다음 P2, P3
2. 항목마다 `style` + `prompt`로 VARCO에서 생성, `duration_sec`에 맞춤
3. `variations` 개수만큼 생성해 규칙대로 저장
4. 들어보고 아래 품질 기준에 어긋나면 프롬프트를 다듬어 재생성
5. 끝나면 `Docs/Sound/progress.json`에 결과 기록 (아래 형식)

### progress.json 형식
```json
{ "done": [ { "id": "HIT_Light", "files": ["SFX/Hit/HIT_Light_01.wav"], "prompt_used": "…", "note": "" } ],
  "failed": [ { "id": "QUEEN_Intro", "reason": "합창이 너무 길게 나옴" } ] }
```

## 품질 기준
- 금속성 칼날 소리(쇳소리, 검 뽑는 소리)가 섞이면 재생성
- 타격음(`HIT_*`)은 시작이 즉시 터져야 함 (앞 무음 0.01초 이내) — 히트스톱 첫 프레임에 재생됨
- 루프 항목은 이음새에서 클릭/튐이 없어야 함
- 같은 ID의 변형끼리 볼륨이 비슷해야 함
- 3D 항목은 모노

## 범위 밖 (하지 말 것)
- 게임 코드(`Assets/Scripts`) 수정, 사운드 재생 연결 — 생성 후 별도로 진행
- `id` 변경, 목록에 없는 사운드 추가 (필요하면 `progress.json`의 note에 제안만 기록)
