# KING: Last Piece — 사운드 리스트

현재 코드의 게임 이벤트 기준으로 정리한 전체 사운드 목록입니다. (현재 프로젝트에는 오디오가 하나도 없습니다.)

- **우선순위**: P1 = 플레이 감각에 필수 · P2 = 완성도 · P3 = 폴리시
- **유형**: 3D = 월드 위치 사운드 · 2D = UI/전역 · Loop = 반복 재생
- **변형**: 같은 소리 반복 피로를 줄이기 위한 권장 베리에이션 개수 (재생 시 피치 ±5% 랜덤 권장)
- 톤 가이드: 기물은 **나무·대리석·석재** 질감. 킹은 무게감 있는 대리석, 흑 기물은 흑단/흑요석 느낌. 금속 칼소리는 쓰지 않음(몸으로 휘두르는 공격).

## 요약

| 구분 | 개수 |
|---|---|
| 효과음 (SFX) | 약 100종 (베리에이션 제외) |
| 루프 사운드 | 6종 (슬로우모션, 저체력, 무방비, 스로우 회전, 적 이동, 홀 앰비언스) |
| BGM | 4곡 |

**P1만 먼저 만든다면** (약 55종): 회피·저스트 회피, 공격 5종 + 강공, 명중(일반/강), 균열, 무방비·띄우기·착지, 스로우 전 과정, 킹 피격/회복/사망, 적 등장·예비동작·붕괴, 기물별 핵심 공격, 퀸 핵심 패턴, 라운드 시작/클리어/승리/패배, 락온, BGM 3곡.

### 구현 참고
- **히트스톱 동기화**: 명중음은 히트스톱 첫 프레임에 재생해야 타격감이 삽니다.
- **슬로우모션**: 저스트 회피 중에는 효과음 피치를 0.6~0.7로 낮추고 로우패스 필터를 적용하면 연출이 살아납니다 (킹 사운드는 `PlayerDeltaTime`처럼 예외 처리).
- **동시 재생 제한**: 회오리·강공처럼 다수 명중 시 HIT_Light가 한 프레임에 여러 번 겹치므로 같은 ID는 프레임당 2~3개로 제한.
- **기물 크기별 볼륨/피치**: 붕괴·착지음은 폰(높은 피치, 작게) → 룩/퀸(낮은 피치, 크게).
