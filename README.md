# KING: The Last Piece

> 모든 백색 기물이 쓰러졌다. 보드 위에 남은 것은 킹 하나뿐.

체스 기물들과 싸우는 **라이트 소울라이크 아레나 액션** 게임입니다.
플레이어는 마지막 남은 **백색 킹**이 되어, 체스판 아레나 위에서 웨이브로 등장하는 흑색 기물들을 상대합니다.

- 엔진: Unity 6 (6000.3.23f1), URP, Input System
- 씬 설정 불필요: `SampleScene`(또는 아무 씬)에서 Play를 누르면 `GameBootstrap`이 아레나·플레이어·카메라·HUD를 런타임에 자동 생성합니다.

## 소울라이크 요소 (가볍게)

| 요소 | 구현 |
| --- | --- |
| 스태미나 | 공격·달리기에 소모, 행동 후 잠시 뒤 회복. 약공격(콤보)은 표기 비용의 35%만 소모 |
| 달리기 | Shift 누르는 동안 8.2 속도로 질주 (기력 14/초 소모, 바닥나면 20 회복 전까지 불가), 락온 중에도 이동 방향으로 달림 |
| 구르기 | 무적 프레임(i-frame) 포함, 입력 없으면 백스텝. 기력 대신 **연속 3회 횟수제** — 0.35초 후부터 0.7초마다 1회씩 회복 |
| 저스트 회피 | 공격이 닿기 0.2초 이내에 구르면(빗나간 경우 포함) **슬로우 모션** + 회피 1회 환급 → 이때 좌클릭으로 **로열 스로우** |
| 오토 타겟팅 | 표시 없음. 락온 없이 공격하면 근처(공격 사거리+0.6, 2.5~4.5) 적들 중 **가장 많은 적을 맞히는 방향**을 자동 선택(각 적 방향·적 사이 방향 후보 비교, 입력은 동점일 때만 반영). 근처 적이 있으면 이동 입력과 무관하게 적 방향으로 공격, 멀면 작동 안 함 |
| 회피 방향 보정 | 곧 맞을 공격이 있으면 구르기 방향을 자동 조정 — 비숍·룩 등 돌진은 경로에 **수직**, 도약·내려찍기는 원 **바깥**으로. 이미 빠져나가는 입력은 그대로 존중 |
| 공격 중 회피 | 공격의 첫 판정 순간만 빼고 선딜·후딜 언제든 구르기로 캔슬 |
| 몸통 공격 | 무기 없이 킹이 몸 자체를 휘둘러 공격 — 좌우 채찍 스윙 → 360° 회전 → 공중제비 내려찍기 4단 콤보, 강공격은 도약 후 쓰러지는 체크메이트 토플 |
| 락온 | 대상 고정 카메라 + 스트레이프 이동 |
| 회복 아이템 | Royal Flask 3개, 사용 중 이동 느려지고 피격 시 낭비 |
| 텔레그래프 | 적 공격 전 붉은 발광 + 바닥 위험 범위 표시 |
| 경직 시스템 | 일반 적: 피격 시 경직 + 숨겨진 게이지 누적 → 가득 차면 **취약**(금빛 연출) → 다음 타격에 **띄우기**·행동 취소 → 공중 추가타(상승량 감소) → 착지·기상. 공격 중에는 슈퍼아머. 보스는 별도 체간(poise) |
| 사망 | **CHECKMATE** 화면, 현재 웨이브부터 재도전 |
| 기물 파괴 | 적 기물은 쓰러지는 대신 금이 가며 번쩍인 뒤 **성벽처럼 돌덩이로 무너져 내림** (아래부터 무너지고 위가 뒤따라 떨어짐 → 튕기고 쌓였다가 바닥으로 가라앉음). [캡처](Docs/AttackLab/11_Death_Crumble.png) |
| 웨이브 사이 휴식 | 플라스크 리필 + 체력 일부 회복 (모닥불 대체) |


## 공격 방식 — Attack Lab

킹은 칼 없이 **몸 전체를 휘둘러** 싸웁니다. 몸은 받침 테두리를 축으로 기울고, 회전하고, 뛰고, 쓰러집니다(절차적 포즈 + 왕관 트레일).
`Assets/Scenes/AttackLab.unity` 테스트 씬에서 6가지 후보를 허수아비 6개(정면·대각·측면·후방)에 비교할 수 있습니다.

| # | 방식 | 약공격 | 강공격 | 판정 |
| --- | --- | --- | --- | --- |
| 1 | Royal Spin (회전 팽이) | 기울여 360° 회전 | 상승 2연 회전 | 전방위라 위치 선정이 무의미, 실루엣 변화 적음 |
| 2 | Crown Smash (왕관 내려찍기) | 뒤로 젖혔다 앞으로 박기 | 바닥에 완전히 쓰러지며 충격파 | 강공격 그림이 가장 강렬, 약공격은 70°로 좁음 |
| 3 | Pendulum (몸통 휘두르기) | 좌우 교대 스윙 | 240° 대회전 | 트레일 궤적이 가장 크고 읽기 쉬움 |
| 4 | Royal Stomp (착수 내려찍기) | 점프 후 착지 | 공중제비 메테오 | 착지 충격파는 좋으나 약공격 선딜 0.40s로 느림 |
| 5 | Royal Charge (돌진 박치기) | 짧은 돌진 | 긴 로켓 돌진 | 시각 변화·명중 모두 가장 약함 |
| **6** | **Royal Ensemble (왕의 연무) ★채택** | 로열 휩 R→L → L→R → 로열 사이클론 → 로열 메테오 | 체크메이트 토플 | 아래 참고 |

**채택: Royal Ensemble** — 평가에서 가장 좋았던 요소를 하나의 리듬으로 묶었습니다.
- 1·2타 **로열 휩**: 64°까지 깊게 기울며 몸을 띄워 휘두르는 채찍 스윙 (선딜 0.13s, 220°, 판정 중심을 앞으로 0.6 이동한 사거리 2.8) — 바닥에 금빛 베기 궤적
- 3타 **로열 사이클론**: 크게 휘청이고 들썩이며 **3바퀴(1080°)** 격렬하게 회전, 왕관에서 불꽃을 흩뿌리며 **주변 360°를 2회** 타격 (사거리 3.4, 바닥 원형 궤적 2중)
- 4타 **로열 메테오**: 도약해 공중에서 앞으로 한 바퀴 공중제비 → 착지 충격파 + 줌 펀치 (사거리 3.2)
- 강공격 **체크메이트 토플**: 뒤로 젖혔다 도약해 앞으로 완전히 쓰러지며 내려찍기 → 여진 충격파(사거리 3.8). 선딜 0.62s의 고위험 고보상 시그니처 기술
- 진자 스윙은 **왕관이 실제로 지나간 각도의 적만** 순서대로 맞습니다(스윕 판정)

자동 평가: Attack Lab 플레이어 빌드를 `-autoshot <폴더>` 인자로 실행하면 스타일별 콘택트 시트(행: 약공격 콤보 각 타·강공격 / 열: 준비→타격→회복)와 `stats.tsv`를 생성합니다. 결과물은 [`Docs/AttackLab`](Docs/AttackLab)에 있습니다.

Lab 조작: `1`–`6` 스타일 전환 · `C` 허수아비 리셋 · `G` 공격하는 폰 소환 · `H` 히트스톱 켜기/끄기 · 실험실에서는 **기력 무제한**

> **히트스톱**: 공격이 처음 적중하는 순간 0.04~0.12초 동안 게임 속도를 10%로 늦춰 타격감을 줍니다. 공격 한 번당 한 번만 걸립니다.

## 저스트 회피 → 로열 스로우

1. 적 공격이 **닿기 직전 0.2초 안에** 구르면 저스트 회피 발동 (공격을 무적으로 흘려보내거나, 아슬아슬하게 빗나가도 인정)
2. **슬로우 모션 1.6초** — 적은 25% 속도, 킹은 정상 속도. 화면이 푸르게 물들고 레터박스 + `LMB — ROYAL THROW` 표시, 회피 1회 환급
3. 슬로우 중 **좌클릭** → 킹이 그 적 기물에게 붙어 **붙잡아 두 바퀴 휘두름** (휘두르는 기물에 닿은 다른 적도 25 피해)
4. 놓는 순간 **멀리 내던짐** — 날아가는 기물은 경로의 적을 쓰러뜨리고(22 피해), 보드 끝에 부딪히고, **착지할 때 75 피해** + 경직 (피해가 착지에 몰려 있어 약한 기물도 반드시 날아간 뒤 쓰러짐)

자동 검증 결과는 [`Docs/AttackLab/7_Perfect_Dodge_Royal_Throw.png`](Docs/AttackLab/7_Perfect_Dodge_Royal_Throw.png) (룩의 돌진을 저스트 회피 → 붙잡아 휘두르기 → 투척).

## 경직 시스템 (일반 적, 보스 제외)

| 상태 | 피격 반응 | 게이지 |
| --- | --- | --- |
| 일반 | 경직 모션(뒤로 밀림) | 누적 |
| 공격 중 (선딜~판정 끝, 슈퍼아머) | 무반응, 공격 지속 | 누적 |
| 취약 | 띄우기 + 행동 취소 | 정지 |
| 공중 | 추가 띄우기 (타격마다 상승량 ×0.6) | 정지 |

- 공격마다 HP 피해와 경직 피해가 분리되어 있습니다 (`HitWindow.damage` / `HitWindow.poise`).
- 적별 설정은 `StaggerProfile` (ScriptableObject — `Create ▸ KING ▸ Stagger Profile`로 에셋 생성 가능): 최대 게이지, 감소 지연, 초당 감소량, 취약 지속시간, 띄우는 힘, 경직 시간.
- 후딜(Recover)에는 아머가 없어 반격 타이밍이 됩니다. 행동이 취소되면 텔레그래프가 꺼지고 공격 토큰이 반납됩니다.
- 착지 → 기상 → 게이지 0 / 취약 시간 초과 → 게이지 0 / 맞지 않으면 게이지 자연 감소.
- 게이지는 숨기고, 취약 진입은 금빛 플래시·충격파, 취약 중에는 머리 위 금빛 불꽃 + 휘청임으로 표시합니다.
- 보스(퀸)는 컴포넌트를 붙이지 않고 기존 체간(poise) 방식을 씁니다.

| 적 | 최대 게이지 | 취약 시간 | 띄우는 힘 |
| --- | --- | --- | --- |
| Pawn | 26 | 3.0s | 7.5 |
| Knight / Bishop | 60 | 2.5s | 6.5 |
| Rook | 110 | 2.0s | 4.8 |

자동 검증: [`Docs/AttackLab/9_Stagger_System.png`](Docs/AttackLab/9_Stagger_System.png) — 폰에게 콤보를 넣으면 경직 → 취약 → 띄우기·공중 추가타 → 기상 → 처치 (약 3초).

## 흑색 기물 (적)

모든 기물이 `Resources/Models`의 디자인 모델을 사용합니다(텍스처 유지). [모델 캡처](Docs/AttackLab/8_Piece_Models.png)

체스 이동 규칙을 공격 패턴으로 옮겼습니다.

- **Pawn** (HP 100 ≈ 약공격 1.5사이클) – 느리게 접근해 전방 찌르기
- **Knight** (HP 265 ≈ 4사이클) – L자 홉으로 거리 조절 후, 킹의 위치로 도약 내려찍기 (원형 범위)
- **Bishop** (HP 265 ≈ 4사이클) – 킹의 대각선 위로 미끄러져 정렬한 뒤 보드 끝까지 대각선 돌진
- **Rook** (HP 380) – 같은 랭크/파일로 정렬해 직선 돌진, 근접 시 내려찍기
- **The Black Queen (보스, HP 700)** – 연속 돌진, 도약, 광역 "Check" 내려찍기. 체력 50% 이하에서 폰 소환 + 공격 가속

## 라운드 (10)

> 약공격 4타 1사이클 = 66 피해 기준으로 체력을 정했습니다.

1. The Opening — 폰 ×4
2. Knight's Gambit — 나이트 + 폰 ×2
3. The Long Diagonal — 비숍 + 폰 ×3
4. Minor Pieces — 나이트 + 비숍 + 폰 ×2
5. Castle Walls — 룩 + 폰 ×3
6. Twin Cavalry — 나이트 ×2 + 비숍
7. Fianchetto — 비숍 ×2 + 룩
8. Rook Lift — 룩 ×2 + 나이트 + 폰 ×2
9. The Vanguard — 나이트 ×2 + 비숍 ×2 + 룩 + 폰 ×2
10. **The Black Army** — 흑 기물 전원: 폰 ×8, 룩·나이트·비숍 ×2, **퀸** (보스, 50% 이하에서 폰 추가 소환)

라운드를 클리어하면 킹은 하던 동작을 끝까지 마친 뒤(입력 무시), 약 2.3초 후 e1로 돌아가고 다음 라운드가 시작됩니다.

기물은 실제 체스 초기 배치 칸(d7, g8, a8 …)에서 등장하고, 킹은 e1에서 시작합니다.
