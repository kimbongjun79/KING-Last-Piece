# KING: The Last Piece

> 모든 백색 기물이 쓰러졌다. 보드 위에 남은 것은 킹 하나뿐.

체스 기물들과 싸우는 **라이트 소울라이크 아레나 액션** 게임입니다.
플레이어는 마지막 남은 **백색 킹**이 되어, 체스판 아레나 위에서 웨이브로 등장하는 흑색 기물들을 상대합니다.

- 엔진: Unity 6 (6000.3.23f1), URP, Input System
- 씬 설정 불필요: `SampleScene`(또는 아무 씬)에서 Play를 누르면 `GameBootstrap`이 아레나·플레이어·카메라·HUD를 런타임에 자동 생성합니다.

## 소울라이크 요소 (가볍게)

| 요소 | 구현 |
| --- | --- |
| 스태미나 | 공격·구르기에 소모, 행동 후 잠시 뒤 회복 |
| 구르기 | 무적 프레임(i-frame) 포함, 입력 없으면 백스텝 |
| 몸통 공격 | 무기 없이 킹이 몸 자체를 휘둘러 공격 — 좌우 진자 → 회전 피니시 3단 콤보, 강공격은 앞으로 쓰러지는 왕관 내려찍기 |
| 락온 | 대상 고정 카메라 + 스트레이프 이동 |
| 회복 아이템 | Royal Flask 3개, 사용 중 이동 느려지고 피격 시 낭비 |
| 텔레그래프 | 적 공격 전 붉은 발광 + 바닥 위험 범위 표시 |
| 강인도/경직 | 적의 poise를 깎으면 경직 → 반격 찬스 |
| 사망 | **CHECKMATE** 화면, 현재 웨이브부터 재도전 |
| 웨이브 사이 휴식 | 플라스크 리필 + 체력 일부 회복 (모닥불 대체) |


## 공격 방식 — Attack Lab

킹은 칼 없이 **몸 전체를 휘둘러** 싸웁니다. 몸은 받침 테두리를 축으로 기울고, 회전하고, 뛰고, 쓰러집니다(절차적 포즈 + 왕관 트레일).
`Assets/Scenes/AttackLab.unity` 테스트 씬에서 6가지 후보를 허수아비 6개(정면·대각·측면·후방)에 비교할 수 있습니다.

| # | 방식 | 약공격 | 강공격 | 판정 |
| --- | --- | --- | --- | --- |
| 1 | Royal Spin (회전 팽이) | 기울여 360° 회전 | 상승 2연 회전 | 전방위라 위치 선정이 무의미, 실루엣 변화 적음 |
| 2 | Crown Smash (왕관 내려찍기) | 뒤로 젖혔다 앞으로 박기 | 바닥에 완전히 쓰러지며 충격파 | 강공격 그림이 가장 강렬, 약공격은 70°로 좁음 |
| 3 | Pendulum (몸통 휘두르기) | 좌우 교대 스윙 | 240° 대회전 | 트레일 궤적이 가장 크고 읽기 쉬움 |
| 4 | Royal Stomp (착수 내려찍기) | 점프 후 착지 | 공중제비 메테오 | 착지 충격파는 좋으나 약공격 선딜 0.40s로 느림 |
| 5 | Royal Charge (돌진 박치기) | 짧은 돌진 | 긴 로켓 돌진 | 시각 변화·명중 모두 가장 약함 |
| **6** | **Royal Ensemble (왕의 연무) ★채택** | 진자 R→L → L→R → 회전 피니시 | Crown Smash 쓰러지기 | 아래 참고 |

**채택: Royal Ensemble** — 평가에서 가장 좋았던 요소를 하나의 리듬으로 묶었습니다.
- 약공격은 가장 읽기 쉬운 **진자 스윙**(선딜 0.15s, 180°)으로 시작해, 3타째 **360° 회전 피니시**로 둘러싼 적을 정리 → 콤보 DPS 36.5 (Spin 30.3, Stomp 29.2, Charge 28.9보다 높음)
- 강공격은 시각적으로 가장 강렬한 **"킹이 쓰러지는" 토플** — 체크메이트 이미지와 겹치는 게임의 시그니처 동작이자, 선딜 0.60s·후딜이 긴 고위험 고보상 기술
- 진자 스윙은 **왕관이 실제로 지나간 각도의 적만** 순서대로 맞습니다(스윕 판정)

자동 평가: Attack Lab 플레이어 빌드를 `-autoshot <폴더>` 인자로 실행하면 스타일별 콘택트 시트(행: 약1·약2(·약3)·강 / 열: 준비→타격→회복)와 `stats.tsv`를 생성합니다. 결과물은 [`Docs/AttackLab`](Docs/AttackLab)에 있습니다.

Lab 조작: `1`–`6` 스타일 전환 · `C` 허수아비 리셋 · `G` 공격하는 폰 소환

## 흑색 기물 (적)

체스 이동 규칙을 공격 패턴으로 옮겼습니다.

- **Pawn** – 느리게 접근해 전방 찌르기
- **Knight** – L자 홉으로 거리 조절 후, 킹의 위치로 도약 내려찍기 (원형 범위)
- **Bishop** – 킹의 대각선 위로 미끄러져 정렬한 뒤 보드 끝까지 대각선 돌진
- **Rook** – 같은 랭크/파일로 정렬해 직선 돌진, 근접 시 내려찍기, 공격 중 슈퍼아머
- **The Black Queen (보스)** – 연속 돌진, 도약, 광역 "Check" 내려찍기. 체력 50% 이하에서 폰 소환 + 공격 가속

## 웨이브

1. The Opening — 폰 ×3
2. Knight's Gambit — 나이트 + 폰 ×2
3. The Long Diagonal — 비숍 + 나이트 + 폰 ×2
4. Castle Walls — 룩 + 비숍 + 폰 ×2
5. **The Black Queen** — 보스전

기물은 실제 체스 초기 배치 칸(d7, g8, a8 …)에서 등장하고, 킹은 e1에서 시작합니다.
