# KING: The Last Piece

> 모든 백색 기물이 쓰러졌다. 보드 위에 남은 것은 킹 하나뿐.

체스 기물들과 싸우는 **라이트 소울라이크 아레나 액션** 게임입니다.
플레이어는 마지막 남은 **백색 킹**이 되어, 체스판 아레나 위에서 웨이브로 등장하는 흑색 기물들을 상대합니다.

- 엔진: Unity 6 (6000.3.23f1), URP, Input System
- 씬 설정 불필요: `SampleScene`(또는 아무 씬)에서 Play를 누르면 `GameBootstrap`이 아레나·플레이어·카메라·HUD를 런타임에 자동 생성합니다.

## 소울라이크 요소 (가볍게)

| 요소 | 구현 |
| --- | --- |
| 스태미나 | 공격·달리기에 소모, 행동 후 잠시 뒤 회복. 약공격(콤보)은 표기 비용의 35%만 소모 |
| 달리기 | Shift 누르는 동안 8.2 속도로 질주 (기력 14/초 소모, 바닥나면 20 회복 전까지 불가), 락온 중에도 이동 방향으로 달림 |
| 구르기 | 무적 프레임(i-frame) 포함, 입력 없으면 백스텝. 기력 대신 **연속 3회 횟수제** — 0.35초 후부터 0.7초마다 1회씩 회복 |
| 저스트 회피 | 공격이 닿기 0.2초 이내에 구르면(빗나간 경우 포함) **슬로우 모션** + 회피 1회 환급 → 이때 좌클릭으로 **로열 스로우** |
| 오토 타겟팅 | 표시 없음. 락온 없이 공격하면 근처(공격 사거리+0.6, 2.5~4.5) 적들 중 **가장 많은 적을 맞히는 방향**을 자동 선택(각 적 방향·적 사이 방향 후보 비교, 입력은 동점일 때만 반영). 근처 적이 있으면 이동 입력과 무관하게 적 방향으로 공격, 멀면 작동 안 함 |

| 공격 중 회피 | 공격의 첫 판정 순간만 빼고 선딜·후딜 언제든 구르기로 캔슬 |
| 몸통 공격 | 무기 없이 킹이 몸 자체를 휘둘러 공격 — (중거리면 돌진 박치기로 시작) 좌우 채찍 스윙 → 360° 회전 → 공중제비 내려찍기 4단 콤보, 우클릭 강공격은 긴 준비 뒤 한 번만 적중하는 강력한 베기 |

| 텔레그래프 | 적 공격 전 붉은 발광 + 바닥 위험 범위 표시 |
| 경직 시스템 | 일반 적: 피격 시 경직 + 숨겨진 게이지 누적 → 가득 차면 **취약**(금빛 연출) → 다음 타격에 **띄우기**·행동 취소 → 공중 추가타(상승량 감소) → 착지·기상. 공격 중에는 슈퍼아머. 보스는 별도 체간(poise) |

| 웨이브 사이 휴식 | 플라스크 리필 + 체력 일부 회복 (모닥불 대체) |


## 공격 방식 (확정: Royal Ensemble)

킹은 칼 없이 **몸 전체를 휘둘러** 싸웁니다. 몸은 받침 테두리를 축으로 기울고, 회전하고, 뛰고, 쓰러집니다(절차적 포즈 + 왕관 트레일).
6가지 후보를 허수아비 6개(정면·대각·측면·후방)에 비교해 **Royal Ensemble**로 확정했습니다. 비교 기록은 [`Docs/AttackLab`](Docs/AttackLab)에 남아 있습니다.

| # | 방식 | 약공격 | 강공격 | 판정 |
| --- | --- | --- | --- | --- |
| 1 | Royal Spin (회전 팽이) | 기울여 360° 회전 | 상승 2연 회전 | 전방위라 위치 선정이 무의미, 실루엣 변화 적음 |
| 2 | Crown Smash (왕관 내려찍기) | 뒤로 젖혔다 앞으로 박기 | 바닥에 완전히 쓰러지며 충격파 | 강공격 그림이 가장 강렬, 약공격은 70°로 좁음 |
| 3 | Pendulum (몸통 휘두르기) | 좌우 교대 스윙 | 240° 대회전 | 트레일 궤적이 가장 크고 읽기 쉬움 |
| 4 | Royal Stomp (착수 내려찍기) | 점프 후 착지 | 공중제비 메테오 | 착지 충격파는 좋으나 약공격 선딜 0.40s로 느림 |
| 5 | Royal Charge (돌진 박치기) | 짧은 돌진 | 긴 로켓 돌진 | 시각 변화·명중 모두 가장 약함 |
| **6** | **Royal Ensemble (왕의 연무) ★채택** | (중거리: 로열 차지 →) 로열 휩 R→L → L→R → 로열 사이클론 → 로열 메테오 | 도약 X자 내려베기 (3안 비교 중) | 아래 참고 |

**채택: Royal Ensemble** — 평가에서 가장 좋았던 요소를 하나의 리듬으로 묶었습니다.
- 1·2타 **로열 휩**: 64°까지 깊게 기울며 몸을 띄워 휘두르는 채찍 스윙 (선딜 0.13s, 220°, 사거리 2.8) — 바닥에 금빛 베기 궤적
- 3타 **로열 사이클론**: 크게 휘청이고 들썩이며 **3바퀴(1080°)** 격렬하게 회전, 왕관에서 불꽃을 흩뿌리며 **주변 360°를 2회** 타격 (사거리 3.4, 바닥 원형 궤적 2중)
- 4타 **로열 메테오**: 도약해 공중에서 앞으로 한 바퀴 공중제비 → 착지 충격파 + 줌 펀치 (사거리 3.2)
- 중거리 오프너 **로열 차지**: 1타가 닿지 않고 7 이내에 적이 있으면 그 거리만큼 돌진 박치기 후 1→2→3→4타로 이어짐 (5번 Royal Charge의 약공격)
- 우클릭 강공격 **도약 X자 내려베기**: 길게 몸을 압축해 점프를 준비한 뒤 빠르게 이륙·전진, 하강할 때 **우상단→좌하단·좌상단→우하단 슬래시를 같은 프레임에 출력**합니다. 이펙트는 두 줄이지만 타격 판정은 한 번(220°, 사거리 4.3, 피해 46, **기력 48**). 메인 게임은 임시로 1안(짧은 도약)을 사용하며, 최종 모션은 EffectsLab 플레이 후 선택합니다.
- 진자 스윙은 **왕관이 실제로 지나간 각도의 적만** 순서대로 맞습니다(스윕 판정)

자동 회귀 테스트: 연습장 플레이어 빌드를 `-autoshot <폴더>` 인자로 실행하면 공격·저스트 회피·경직·오토 에임·사망 연출 캡처와 `stats.tsv`를 생성합니다 ([`Docs/AttackLab`](Docs/AttackLab)).

| 1 | 짧은 도약 (게임 임시 적용) | 0.62초 압축 후 0.14초 만에 최고점, 0.93초에 타격 |
| 2 | 깊은 도약 | 0.70초 압축 후 0.16초 만에 높은 최고점, 1.03초에 타격 |

이전 A/B/C 이펙트 선택은 제거했습니다. 모든 씬은 기존 **Board Ripple** 타격·바닥 이펙트로 고정합니다. [`Docs/EffectsLab`](Docs/EffectsLab)의 예전 스크린샷은 이전 이펙트 비교 기록입니다.

### 적용 중인 공격 이펙트 (Board Ripple)

- **바닥 균열 = URP 데칼**: `Resources/Textures/Crack*.png`(바르코 생성)을 `KING ▸ Setup ▸ Effects Assets`가 투명 데칼 텍스처로 변환(흰 배경 → 투명, 가장자리 페이드) → 무작위 이미지·회전으로 바닥에 찍히고 약 3초 뒤 사라짐. 빛나는 균열은 사용하지 않음
- **공격 궤적 = NamuFX Simple Stylized Slash vol2** (`Resources/FxLibrary.asset`에 등록)
  - 1·2타: Slash_B 금색 — 왕관 궤적 대신 왕관 높이에서 재생 (슬래시가 나오는 공격은 왕관 트레일 끔)
  - 3타 사이클론: Slash_Aoe_A 금색 버스트
  - 4타 메테오: 슬래시 없이 **먼지**(NamuFX 연기·먼지 레이어만, 고리 모양) + 균열 데칼. 우클릭 강베기는 기존 Slash_B의 수직 변형을 반대 방향 45°로 두 겹 같은 프레임에 재생해 X자를 만들고 바닥 파동·먼지를 사용
- 균열 크기는 충격 반경의 최대 2배(최대 6). 데칼 투사 깊이를 늘려 솟은 칸에도 균열이 보임
  - 금색 틴트는 시작색·수명 그라디언트·트레일을 바꾸고, 커스텀 데이터 색을 끈 머티리얼 사본을 사용. 먼지·연기는 중립 회갈색
- NamuFX는 서드파티 에셋이라 **저장소에 포함하지 않습니다**(로컬 `Assets/NamuFX`). 없으면 기존 바닥 초승달 궤적으로 대체됩니다.

> **히트스톱**: 공격이 처음 적중하는 순간 0.04~0.12초 동안 게임 속도를 10%로 늦춰 타격감을 줍니다. 공격 한 번당 한 번만 걸립니다.

## 저스트 회피 → 로열 스로우

1. 적 공격이 **닿기 직전 0.2초 안에** 구르면 저스트 회피 발동 (공격을 무적으로 흘려보내거나, 아슬아슬하게 빗나가도 인정)
2. **슬로우 모션 1.6초** — 적은 25% 속도, 킹은 정상 속도. **그동안 킹은 무적** (뒤따르는 공격도 맞지 않음). 화면이 푸르게 물들고 레터박스 + `LMB — ROYAL THROW` 표시, 회피 1회 환급
3. 슬로우 중 **좌클릭** → 킹이 그 적 기물에게 붙어 **붙잡아 두 바퀴 휘두름** (휘두르는 기물에 닿은 다른 적도 25 피해)
4. 놓는 순간 **멀리 내던짐** — 날아가는 기물은 경로의 적을 쓰러뜨리고(22 피해), 보드 끝에 부딪히고, **착지할 때 75 피해** + 경직 (피해가 착지에 몰려 있어 약한 기물도 반드시 날아간 뒤 쓰러짐)

자동 검증 결과는 [`Docs/AttackLab/7_Perfect_Dodge_Royal_Throw.png`](Docs/AttackLab/7_Perfect_Dodge_Royal_Throw.png) (룩의 돌진을 저스트 회피 → 붙잡아 휘두르기 → 투척).

## 경직 시스템 (일반 적, 보스 제외)

| 상태 | 피격 반응 | 게이지 |
| --- | --- | --- |
| 일반 | 경직 모션(뒤로 밀림) | 누적 |
| 공격 중 (선딜~판정 끝, 슈퍼아머) | 무반응, 공격 지속 | 누적 |
| 취약 | 띄우기 + 행동 취소 | 정지 |
| 공중 | 추가 띄우기 (타격마다 상승량 ×0.6) | 정지 |

- 공격마다 HP 피해와 경직 피해가 분리되어 있습니다 (`HitWindow.damage` / `HitWindow.poise`).
- 적별 설정은 `StaggerProfile` (ScriptableObject — `Create ▸ KING ▸ Stagger Profile`로 에셋 생성 가능): 최대 게이지, 감소 지연, 초당 감소량, 취약 지속시간, 띄우는 힘, 경직 시간.
- 후딜(Recover)에는 아머가 없어 반격 타이밍이 됩니다. 행동이 취소되면 텔레그래프가 꺼지고 공격 토큰이 반납됩니다.
- 착지 → 기상 → 게이지 0 / 취약 시간 초과 → 게이지 0 / 맞지 않으면 게이지 자연 감소.
- 게이지는 숨기고, 취약 진입은 금빛 플래시·충격파, 취약 중에는 머리 위 금빛 불꽃 + 휘청임으로 표시합니다.
- 보스(퀸)는 컴포넌트를 붙이지 않고 기존 체간(poise) 방식을 씁니다.

| 적 | 최대 게이지 | 취약 시간 | 띄우는 힘 |
| --- | --- | --- | --- |
| Pawn | 26 | 3.0s | 7.5 |
| Knight / Bishop | 60 | 2.5s | 6.5 |
| Rook | 110 | 2.0s | 4.8 |

자동 검증: [`Docs/AttackLab/9_Stagger_System.png`](Docs/AttackLab/9_Stagger_System.png) — 폰에게 콤보를 넣으면 경직 → 취약 → 띄우기·공중 추가타 → 기상 → 처치 (약 3초).

## 보스: 체스메가트론 (시범 — 연습장 `6`)

검은 **폰 27개로만** 이루어진 거상. 3×3칸을 차지하고(높이 약 5.5m — 플레이 화면에 머리까지 보이게, 체력 3000, 체간 420), 네 다리로 서 있어 **킹이 몸 아래로 들어갈 수 있습니다** (막는 것은 발뿐, 구르기는 통과) — 풍차를 피하는 자리지만, 오래 있으면 내려앉습니다. 모든 공격이 **칸 단위**로 바닥에 먼저 표시되고, 대부분 칸 중앙에 자리 잡아 체스판 네 방향 중 하나로 몸을 돌린 뒤 나갑니다. 정면 75° 안의 킹만 공격하므로 옆·뒤로 돌면 돌아서는 동안 틈이 생깁니다.

| 몸 | 폰 구성 |
| --- | --- |
| 골반 | 세운 폰(배) + 다리 뿌리로 뻗은 고관절 폰 4개 |
| 척추·어깨 | 머리·바닥을 엇갈려 겹친 폰 2개 + 좌우로 누운 폰 2개 어깨뼈 |
| 머리 | 큰 폰 + 작은 폰 5개 왕관 (승급하면 커짐) |
| 팔 ×2 | 위팔 폰 + 아래팔 폰(IK), 아래팔 폰의 넓은 바닥이 주먹 |
| 다리 ×4 | 고관절에서 발까지 다리 폰 하나 + 칸 위에 선 큰 발 폰 |

뼈마다 폰 하나가 관절에서 관절까지 정확히 이어지고(팔다리가 길게 당겨지면 길이 방향으로만 조금 늘어남), 팔꿈치·발목·허리는 폰 머리끼리, 어깨·고관절은 폰 바닥이 다른 폰 머리에 얹혀 맞물립니다. 다리는 가늘고 발은 크게.

**절차적 애니메이션** — 관절마다 스프링(지연·오버슈트·흔들림), 발은 칸 중앙에 딛고 몸통 아래 칸이 바뀌면 대각선 두 발씩 한 칸 걸음, 머리는 늘 킹을 봄, 공격은 예비(들어 올림) → 유예(랜덤 정지, 떨림) → 타격(주먹이 칸에 정확히 꽂힘) → 경직(그 자세로 멈춤 = 반격 기회). 체간이 무너지면 스프링이 풀려 주먹을 짚고 주저앉고, 죽으면 머리부터 폰들이 떨어져 흩어지며 부서집니다.

| 패턴 | 예고 | 맞는 칸 (프로모션 후) | 피하는 법 · 반격 |
| --- | --- | --- | --- |
| 돌진 | 머리를 숙이고 주먹을 뒤로, 앞발로 바닥을 긁음 (유예 0~0.5초) | 앞 3줄 × 3칸, 몸이 3칸 돌진 (앞 4줄) | 옆으로 · 1.3초 |
| 내려치기 | 한 주먹을 등 뒤 높이 듦 | 킹의 칸 십자 5칸 (3×3) → 2타는 **그때 킹이 있는 칸**으로 다시 겨눔 | 1타 후 바로 이동 · 2타 후 1.2초 |
| 휩쓸기 | 휩쓸 팔을 옆으로 높이 듦 | 앞 2줄 × 5칸 (앞 3줄) | 뒤로 물러나거나 옆으로 · 1초 |
| 폰 낙하 | 웅크림 | 멀리 있는 킹의 칸 중심 3×3으로 도약 (+ 십자 끝 4칸) | 3×3 밖으로 · 착지 후 1.7초 |
| 내려앉기 | **킹이 몸 아래(3×3)에 1.5초 이상 있으면**, 다리를 펴고 일어서며 팔을 벌림 | 제자리에 주저앉아 몸 중심 9칸 + 둘레 16칸을 한 번에 (각 변 가운데 3칸 더) | 몸 밖 3칸 이상으로 · 앉은 채 1.6초 |
| 풍차 | 가끔(최소 20초 간격) 맵 중앙으로 도약 → 양팔을 낮게 쭉 뻗음 | 착지 3×3, 이어서 **정확히 한 바퀴(360°)** 일정한 속도로 돌며 **판 전체**(몸 아래 3×3만 안전)를 3초(2P 2.5초)에 휩씀. 칸마다 팔이 닿기 0.8초 전에 경고가 켜져 차오르고, 팔이 지나가는 순간 터짐 — 양팔이 한 번씩 지나가므로 한 칸에 두 번 | 몸 아래로 들어가기, 팔을 구르기로 통과, 경고가 꺼진 칸으로 이동 · 1.6초 |
| 프로모션 (50%) | 일어서며 왕관이 자람 (2초) | 몸 둘레 고리 | 2페이즈 시작 |
| 동시 휩쓸기 (2P) | 양팔을 옆으로 높이 (빠름 0.7초) | 앞 3줄 × 7칸 + 몸 양옆 2×2 | 뒤로 크게 · 1.1초 |
| 퀸의 선 (2P) | 두 주먹을 머리 위로 모음 | 몸에서 8방향 줄 | 줄에서 비켜서기(나이트 한 수) · 1.3초 |
| 폰 폭풍 (2P) | 등에서 폰을 뽑아 듦, 3연속 | 킹 칸 + 주변 일부, 던진 폰이 떨어짐 | 매번 칸 이동 · 마지막 후 1.2초 |

2페이즈: 예비 시간 15% 단축, 기존 패턴 범위 증가(위 괄호), 돌진 뒤 내려치기 연계(50%). 자동 캡처: 연습장 빌드를 `-megashot <폴더>`로 실행.

## 흑색 기물 (적)

모든 기물이 `Resources/Models`의 디자인 모델을 사용합니다(텍스처 유지). [모델 캡처](Docs/AttackLab/8_Piece_Models.png)

체스 이동 규칙을 공격 패턴으로 옮겼습니다.

- **Pawn** (HP 100 ≈ 약공격 1.5사이클) – 느리게 접근해 전방 찌르기
- **Knight** (HP 265 ≈ 4사이클) – L자 홉으로 거리 조절 후, 킹의 위치로 도약 내려찍기 (원형 범위)
- **Bishop** (HP 265 ≈ 4사이클) – 킹의 대각선 위로 미끄러져 정렬한 뒤 보드 끝까지 대각선 돌진
- **Rook** (HP 380) – 같은 랭크/파일로 정렬해 직선 돌진, 근접 시 내려찍기
- **The Black Queen (보스, HP 700)** – 연속 돌진, 도약, 광역 "Check" 내려찍기. 체력 50% 이하에서 폰 소환 + 공격 가속

## 라운드 (10) — 일반 모드

> 소울라이크: 한 번에 기물은 적게, 라운드마다 패턴을 읽고 피하는 데 집중합니다. 일부 라운드는 기물을 잡을 때 **증원**이 들어옵니다(조건마다 한 번, 다음 프레임에 떨어짐 — 증원이 남아 있으면 라운드가 끝나지 않음). 일반 모드의 여왕은 체력 50% 이하에서 폰 1개를 부릅니다.

1. 오프닝 — 폰 ×2 + 나이트
2. 비나메이트 — 비숍 + 나이트로 시작, 각각 잡히면 같은 기물이 하나씩 더 (총 비숍 ×2, 나이트 ×2)
3. 룩 더블링 — 룩 + 비숍으로 시작, 어느 기물이든 처음 잡히면 룩 하나 더
4. 어둠에 휩싸인 기사단 — 다크 I 나이트 + 다크 I 룩, 각각 잡히면 일반 기물로 다시 등장
5. **블랙 퀸** — 퀸 단독 (중간 보스)
6. 피앙케토 — 다크 II 비숍 + 다크 I 비숍 ×2
7. 블랙라이온 갬빗 — 다크 II 나이트 + 다크 I 나이트 + 다크 II 폰 + 다크 I 폰, 폰 둘을 모두 잡으면 다크 II 룩 등장
8. 킹 사냥 — 다크 II 룩·비숍·나이트·폰 하나씩, 각각 잡히면 일반 기물로 다시 등장
9. **분노의 어둠 여왕** — 다크 II 퀸 단독 (중간 보스)
10. **체스 메가트론** — 보스 단독 (체력 3000)

### 일반 모드 기록과 온라인 순위

- 클리어하면 승리 화면에 클리어 시간·사망 횟수·피해·포획·완벽한 회피가 나오고, 닉네임을 넣어 확인하면 **일반 모드 온라인 순위**(UGS Leaderboards `normal_best`)에 올라간 뒤 타이틀로 돌아갑니다.
- 순위: **사망이 적을수록, 같으면 클리어 시간이 짧을수록** 위 — 점수 `(999 − 사망) × 100000 + (99999 − 초)` (높을수록 좋음). 메타데이터로 사망·시간·포획·피해 저장.
- 이 기기의 최고 기록(PlayerPrefs)도 따로 남고, 타이틀에서 고른 모드의 최고 기록과 온라인 순위가 보입니다.
- 사망 후 라운드를 다시 해도 사망 횟수와 시간은 이어집니다(1라운드 재도전 포함).
- **UGS 대시보드에 리더보드 `normal_best`를 만들어야 합니다** — 정렬: 높은 점수 우선(내림차순), 갱신: 플레이어 최고 점수 유지. 없으면 순위 패널에 "온라인 순위를 불러올 수 없습니다"가 뜨고 게임은 그대로 진행됩니다.

라운드를 클리어하면 킹은 하던 동작을 끝까지 마친 뒤(입력 무시), 약 2.3초 후 e1로 돌아가고 다음 라운드가 시작됩니다.

기물은 실제 체스 초기 배치 칸(d7, g8, a8 …)에서 등장하고, 킹은 e1에서 시작합니다.
